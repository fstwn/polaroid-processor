Metadata

Written into the headers of every exported file (Explorer, Lightroom). Placeholders: {stem} file name, {n} trailing number, {project} input folder, {format} 600 or Go.

Advanced

Either a resolution or a profile, not both. With neither, the scale comes from the scan (its resolution tag, else the print size). Changing the scale of an exported project exports it again.

Settings apply to the next run and are kept in the project's manifest. Your last choices are the start for new projects (the scale is not carried over). A change shows up in the Export count; a changed scale or profile exports again.
